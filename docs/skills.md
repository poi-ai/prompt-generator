# 補助Skillについて

このリポジトリには、日常的なメンテナンス作業を素早く回すためのプロジェクト専用Skillが用意されています。`.claude/skills/` 配下にあり、リポジトリの一部としてcommit・pushされているため、ローカル・リモート(クラウドのサンドボックス)どちらのセッションでも利用できます。

いずれも `CLAUDE.md` の運用ルール(Issueとセットでの作業・`#<Issue番号>` ブランチ・コミット規約など)に従って動作します。

## `triage-feedback`

このジェネレーターが生成した「フィードバック依頼プロンプト」(`feedback.py`)に対して、実行先のAIが返してきた振り返り(元の指示文のどこが曖昧だったか等)を、このリポジトリ側で直すべき点かどうか仕分けするためのSkillです。

- **入力**: AIが返したフィードバック文をそのまま貼り付ける
- **呼び出し方**: `/triage-feedback <貼り付けたフィードバック文>`
- **動作**: 指摘を「対応候補」「対応不要(理由付き)」に仕分けて提示 → ユーザーの承認を待つ → 承認された分だけIssue作成・実装・動作確認・commit・pushまで行う(マージはしない)

## `quick-fix`

AIのフィードバックを介さず、ユーザー自身がこのジェネレーターを使っていて直接気づいた「直したい点」を、簡単なメモだけでそのまま反映するためのSkillです。仕分けは行わず、内容が明確であれば確認なしでそのまま着手します。

- **入力**: 直したい内容を短く書いたメモ
- **呼び出し方**: `/quick-fix <メモの内容>`
- **動作**: 内容を理解 → Issue作成・実装・動作確認・commit・pushまで行う(マージはしない)

## 共通の注意点

- どちらもpush止まりです。マージするかどうかは毎回明示的に指示してください。
- Skillの中身(判定基準やトリガーの文言)を直したい場合は `.claude/skills/<Skill名>/SKILL.md` を編集してください。
